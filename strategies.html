Retrieval and Purposeful Practice

Help pupils retrieve important knowledge, strengthen connections and apply learning in increasingly demanding ways.

Memory and learning

Retrieval Practice

Retrieval practice requires pupils to bring previously learned knowledge back to mind rather than simply rereading or copying it.

Useful approaches

  • Low-stakes quizzes
  • Brain dumps
  • Flashcards with active recall
  • Short-answer questions
  • Retrieval grids
  • Delayed review of earlier topics

Planning questions

Which knowledge is worth retrieving?

Has enough time passed to make retrieval meaningful?

Will pupils receive useful feedback?

Does the task retrieve understanding or only isolated facts?

Try this

Include questions from the current topic, a recent topic and a topic taught several weeks ago.

Deeper retrieval

Conceptual Retrieval

Retrieval can move beyond factual recall by asking pupils to compare, categorise, connect, explain and apply important concepts.

Useful task types

  • Compare and contrast
  • Sort and categorise
  • Connect two ideas
  • Explain a relationship
  • Create an example or non-example
  • Answer a probing question

Useful prompts

How are these ideas connected?

Which category does this belong to, and why?

What is similar and what is different?

Can you create an example that satisfies these conditions?

Modelling and Guided Practice

Make expert thinking visible, provide supported practice and gradually transfer responsibility to pupils.

Explicit modelling

Live Modelling

Live modelling allows pupils to observe both the finished process and the decisions, checks and corrections made along the way.

Model explicitly

  • How to begin
  • How to select a strategy
  • How to organise information
  • How to check progress
  • How to identify and correct an error
  • How to judge the quality of the outcome

Useful teacher language

I am choosing this method because...

I have noticed that...

This does not look correct, so I will check...

An alternative approach would be...

Try this

Model an imperfect first attempt and demonstrate how an expert diagnoses and improves it.

Supported practice

Guided Practice

Guided practice allows pupils to rehearse a process with prompts, questioning and feedback before working independently.

A useful sequence

  1. Model the process.
  2. Complete an example together.
  3. Ask pupils to explain each next step.
  4. Provide prompts where needed.
  5. Reduce support gradually.
  6. Move to independent application.

Planning questions

Which part requires the most support?

What can pupils already complete independently?

Which prompt will help without giving the answer?

When should the scaffold be removed?

Assessment for Learning

Use evidence of pupil understanding to decide what to teach, revisit or adapt next.

Responsive assessment

Formative Assessment

Formative assessment involves eliciting evidence of learning, interpreting it and using it to make better decisions about what should happen next.

Useful approaches

  • Diagnostic questions
  • Hinge questions
  • Mini-whiteboards
  • Exit questions
  • Whole-class response systems
  • Analysis of errors and misconceptions

Planning questions

What understanding do I need to check?

What will each possible response tell me?

How will I collect evidence from every pupil?

What will I do if pupils are not ready to move on?

Whole-class checking

Mini-Whiteboards

Mini-whiteboards make every pupil’s response visible and allow the teacher to check understanding quickly across the whole class.

Use them for

  • Short calculations
  • Diagrams and representations
  • Vocabulary retrieval
  • Multiple-choice responses
  • Sentence completion
  • Error correction

Good routines

  • Ask the question before pupils write
  • Give sufficient thinking time
  • Use a clear reveal signal
  • Scan patterns rather than individual pupils only
  • Respond to what the answers reveal

Try this

Ask pupils to write both an answer and a confidence rating. Use the combination to decide whether to probe, reteach or move on.

Feedback and Improvement

Give feedback that helps pupils understand the goal, improve their work and take an appropriate next step.

Effective feedback

Feedback That Moves Learning Forward

Effective feedback should be based on high-quality teaching, focus on the learning and give pupils a meaningful opportunity to act.

Feedback should help pupils understand

  • What they are trying to achieve
  • What they have done successfully
  • What requires improvement
  • What action to take next

Planning questions

Will this feedback lead to useful pupil action?

Is the next step specific and manageable?

Will pupils have time to respond?

Could this issue be addressed through whole-class teaching?

Efficient feedback

Whole-Class Feedback

Whole-class feedback identifies common strengths, misconceptions and next steps without repeating the same written comment across many books.

A feedback lesson might include

  • Celebration of strong examples
  • Explicit reteaching of common misconceptions
  • Comparison with a model response
  • Focused correction or redrafting
  • An immediate improvement task

Try this

Record patterns while reviewing work under three headings: strengths, misconceptions and next steps. Plan a short response task for each.

Deliver feedback effectively

Adaptive and Inclusive Teaching

Maintain ambitious goals while responding to pupils’ differences in prior knowledge, language, confidence and need.

Responsive teaching

Adaptive Teaching

Adaptive teaching involves responding to evidence of pupil learning while keeping curriculum goals appropriately ambitious.

Possible adaptations

  • Revisit essential prior knowledge
  • Use a clearer representation
  • Adjust the level of scaffolding
  • Provide additional guided practice
  • Preteach important vocabulary
  • Offer a prompt, model or worked example

Planning questions

What is the essential learning goal?

What barrier is preventing access?

Which adaptation removes the barrier without lowering ambition?

How and when can additional support be reduced?

Collaborative Learning and Classroom Talk

Structure purposeful interaction so that discussion, explanation and collaboration contribute directly to learning.

Structured collaboration

Collaborative Learning

Effective collaboration requires a well-designed task, a shared goal, individual accountability and clear expectations for participation.

Plan for

  • A task that benefits from collaboration
  • Clear roles or responsibilities
  • Individual thinking before discussion
  • Accountability for every pupil
  • A final synthesis or shared outcome

Planning questions

Why is collaboration valuable for this task?

How will every pupil contribute?

What will pupils produce or decide together?

How will individual understanding be checked?

Academic talk

Structured Classroom Talk

Classroom talk can help pupils rehearse vocabulary, explain reasoning, test ideas and refine understanding before producing a written or practical outcome.

Useful structures

  • Think, Pair, Share
  • Turn and Talk
  • Structured debate
  • Paired explanation
  • Socratic discussion
  • Peer critique

Discussion prompts

I agree with this idea because...

I would challenge the claim that...

The strongest evidence is...

Building on that explanation...

An alternative interpretation might be...

Try this

Give pupils one minute of private thinking before discussion, then require each pair to improve one idea before sharing it.
