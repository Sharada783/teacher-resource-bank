Task planning

Using Rich Tasks Effectively

A rich task becomes most powerful when pupils have time to explore, make decisions, compare approaches and explain their reasoning.

Planning questions

Can every pupil make a meaningful start?

Are there several possible approaches?

Where can pupils make a conjecture?

How will pupils compare and evaluate methods?

What opportunities exist for generalisation?

Try this

Present the central problem before demonstrating a method. Allow pupils to notice, test and discuss ideas before drawing the class together.

Reasoning

Developing Mathematical Reasoning

Reasoning requires pupils to communicate how they know, connect representations and justify why a method or conclusion is valid.

Useful prompts

How do you know?

Why must this be true?

Can you represent the idea another way?

Which method is most efficient, and why?

Can you find a counterexample?

Will this always, sometimes or never be true?

Representations

Multiple Representations

Moving between concrete, visual, graphical, symbolic and verbal representations helps pupils recognise mathematical structure and make connections.

Planning prompts

Which representation makes the structure visible?

How does the diagram connect to the equation?

What remains the same across the representations?

Which representation is most efficient here?

Try this

Give pupils two representations of the same idea and ask them to annotate the precise connections between corresponding features.

Classroom challenge

Using Competition Problems in Lessons

Competition questions can be used as teaching tasks, not only as timed tests. Slow exploration often reveals rich opportunities for reasoning and discussion.

Ways to use a problem

  • Remove the multiple-choice answers
  • Ask pupils to predict common wrong answers
  • Compare several solution methods
  • Change one condition and investigate the effect
  • Create a related problem
  • Write a complete justification

Useful prompts

What information matters most?

Can the problem be represented visually?

What would make the problem easier or harder?

How can you prove that no other answer is possible?

Fluency Through Variation

Practice should help pupils notice mathematical structure, not merely repeat identical procedures.
